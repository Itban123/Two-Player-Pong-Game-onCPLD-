# Two-Player Pong Game on CPLD

A two-player Pong game implemented using Verilog HDL
on a CPLD development board.

## Project Overview

This project implements a two-player Pong game
using digital hardware logic.

The design includes:
- Ball movement and collision logic
- Paddle control
- Clock division
- Score tracking
- 8x8 LED matrix display
- 7-segment score display
